# Project Memory Graph

This folder is the lightweight, Obsidian-compatible memory graph for AI Voice Notes To Content.

It exists so the lead developer and specialist agents can resume quickly without rereading every long project document.

Start here:

- [[current-state|Current State]]
- [[index|Memory Index]]
- [[open-questions|Open Questions]]

Rules:

- `current-state.md` is the only mandatory memory file for new chats.
- Follow links only when the task needs more detail.
- Keep notes concise and update them when decisions change.
- Do not store secrets, API keys, private provider credentials, raw voice notes, raw transcripts, or sensitive user content here.
- Use Obsidian wikilinks or relative Markdown links.
