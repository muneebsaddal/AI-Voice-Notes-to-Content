# Lovable Design Final

Status: accepted

The Lovable design direction is the final MVP UI reference unless the user explicitly changes it.

Primary reference:

- `tmp/lovable-project-169832d9-ed67-4bfd-a8ea-aee90c2278e0-2026-05-30`

Implications:

- Port the product feel into React Native / Expo.
- Treat older Figma, Canva, and SVG assets as historical reference only.
- Keep the home screen as a recording surface, not a dashboard.
- Use a blue listening identity.
- Reserve red for destructive actions and true errors.
- Avoid prompt-box-first UI.
