# Native Share Sheet v1

Status: accepted for MVP

The MVP uses the native iOS Share Sheet as the basic Notion export path.

Rules:

- Format shared output as clean Markdown-friendly text.
- Label this as a basic export path, not full Notion sync.
- Do not add Notion OAuth, token storage, workspace selection, page creation, or database mapping in v1.

Future:

- Revisit direct Notion API, database mapping, and richer integrations in v1.5 or v2.
