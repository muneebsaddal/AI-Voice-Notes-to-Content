# MVP Voice To Output

Goal:

Let a user speak naturally and receive a useful structured output within about 30 seconds.

Flow:

1. Open app.
2. See the recording home.
3. Tap the large listening control.
4. Speak naturally.
5. Tap the same control to stop.
6. App processes audio.
7. App suggests an output type.
8. User generates or changes type.
9. App shows editable preview.
10. User saves, copies, shares, or exports.

MVP output types:

- Note
- Todo List
- Email
- Journal Entry
- Content Post

Key UX rules:

- No dashboard-first home.
- No prompt-box-first UI.
- No recording timer.
- Blue listening identity.
- Native-feeling sheets and share flow.
