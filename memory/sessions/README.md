# Session Notes

Save concise session notes here when a specialist handoff should be mirrored into the project memory graph.

Suggested filename:

```text
YYYY-MM-DD-agent-short-task.md
```

Each session note should include:

- Agent
- Skill used
- Task
- Files touched
- What changed
- What was verified
- Commit status
- Decisions linked
- Risks or open questions
- Next task prompt
